Changelog
=========


v0.5.1
------

Released on 2017-04-05.

Packaging:

* Release a universal wheel.

Bug fixes:

* Use 'utf-8' as encoding instead of 'utf8'.



v0.5
----

Released on 2016-05-31.

Dependencies:

* Support Python 3.3, 3.4 and 3.5.
* Drop support of Python 3.2.

Documentation:

* Document ascii_lower.

Bug fixes:

* Fix setup.py to open files as utf-8.


v0.4
----

Released on 2013-11-30.

Dependencies:

* Drop support of Python 3.1.

New features:

* Add ascii_lower function


v0.3
----

Released on 2013-06-29.

Bug fixes:

* Fix passing an Encoding to decode and related functions.


v0.2
----

Released on 2012-12-25.

New features:

* Raise an explict exception on unknown encoding labels.

Documentation:

* Document UTF8.


v0.1
----

Released on 2012-12-23.

New features:

* Add lookup, decode and encode functions.
* Add encodings.
